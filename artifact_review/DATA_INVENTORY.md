# Data inventory

Every input and data source this artifact consumes, classified. Nothing here is
an observational dataset, and the artifact never presents anything as one.

## Classification vocabulary

| Class | Meaning |
|---|---|
| **synthetic fixture** | Authored for this work. Fully specified, not observed. |
| **forensic reconstruction** | Retrospectively reconstructed from a real prior system's published artifacts. Not a contemporaneous record. |
| **generated perturbation** | Produced by a declared stochastic model from a frozen seed. |
| **prior-work external artifact** | Belongs to cited prior work; referenced, not reproduced. |
| **real observed dataset** | Collected from a running system or real-world process. |
| **human data** | Produced by human participants. |
| **deferred / unavailable** | Named in the evaluation plan, not yet in existence. |

paper claims no execution against it. No human-subject data exists.**
